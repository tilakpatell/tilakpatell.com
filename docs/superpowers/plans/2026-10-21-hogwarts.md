# Hogwarts: the plan

The design is `docs/superpowers/specs/2026-10-21-hogwarts-world-design.md`; this is the order of work, a lane a session, a pull request a task. A task goes from this file once its pull request is merged; the lane’s last task updates `docs/superpowers/HANDOFF-worlds.md`’s Hogwarts section.

Every task: its own worktree from `origin/main` (or the lane’s open branch), tests first for anything pure, `npm run lint && npm test && npm run build && node scripts/health.mjs --check --skip build` green, `node scripts/autopilot-check.mjs --routes /hogwarts` with the shots looked at, a plain-sentence commit, a pull request to `main`, merged on CI green, then `main` merged into the lane’s next task. A branch never grows past a working day.
