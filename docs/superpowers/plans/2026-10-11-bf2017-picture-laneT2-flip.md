## Tasks

1. **The rule, pure and tested.** `src/runtime/backend.js`: `pickBackend` takes `tier`; a `'nodes'` module on `low` gets `'webgl'`, on `mid` gets `'webgpu'` with WebGPU and `'webgl'` without, on `high` and `ultra` `'webgpu'` or `'nodes-webgl'`. `src/components/galaxy/surface/module.js` says `shading: 'nodes'`. Tests in `backend.test.js` pin every cell of the tier × gpu × override table. (The classic renderer on `low` and WebGL-only `mid` is the design’s §3.1.)
2. **The scene on both renderers.** `scene.js` already branches on nothing; make it branch on `rt.backend` once: on the classic renderer it builds what it builds today; on the node renderer it builds the node twins. Keep the classic path byte-for-byte (the low tier is its only user now). Split what grows past 800 lines into `surface/nodes/` modules.
3. **Light.** On nodes: the sun through `lib/three/light/sun.js` (CSM 4/2/0 by tier, PCSS, cloud shadows from the record, contact shadows), the sky through `light/sky.js` with the record’s panorama when `picture` is given, fog through `light/fog.js` (height and volumetric, the record’s curve), placed lights through `light/placed.js` (the whole `lights.json`, clustered), probes through `light/probes.js` (crossfade, the ultra grid), `gameLit.js` driving all of it from the record as it drives the classic path today. `groundWorld`’s baked floor mask is the low tier’s only.
4. **Post.** `engine.js`’s `postFor` wired: the per-tier chain of `light/post.js` (ultra everything with TRAA, high with SMAA, mid AO + bloom + SMAA), the record’s linear tonemap and LUT after the bloom (Q6’s order), `headroomAt`’s steps driving the upscaler on the pace’s word. The pace’s `sharpness` becomes the upscaler’s ratio on nodes.
5. **Surface.** Q1’s recipes and variations already draw on nodes above low (`level/index.js:187-200`); pass the site’s weather and `skyVisibility` so Q2’s layered ground and the overlays draw (`compose.js`); Q4’s decals through `decalScene.js` from the pack’s `decals.json`; X’s particles; N’s scatter stays; V’s volumetric cones from the placed lights.
6. **Settings.** `src/components/settings/Settings.jsx` shows the renderer line (“WebGPU”, “WebGL 2, node renderer”, “classic”) read from the runtime, and the `?gpu=` override; a test that `setQuality` re-creates the world on the backend the table says.
7. **Every world, in software GL.** `BUDGET=1 QUALITY=high SCANS=game node scripts/galaxy-check.mjs surface <world>` for all seventeen (`src/components/galaxy/surface/sites/`), on the node renderer (SwiftShader has no WebGPU: it runs `nodes-webgl`; say so in the evidence), with `PHASE_WAIT` raised as E0’s README says. Fix every error the console prints. Record calls, triangles, MB, p50 and p95 per world beside the classic numbers (`docs/superpowers/evidence/bf2017-picture/t2/README.md`), and a shot per world at high, classic beside nodes.
8. **CI.** `ci.yml` runs the seventeen worlds on nodes at high in two shards (the software device, `continue-on-error: false`); the rows are the gate.
9. **The hand-off.** `docs/superpowers/HANDOFF-bf2017.md` gains “The picture-everywhere design” with the lane table from the design’s §4 and this lane’s row; `HANDOFF-galaxy-engine.md`’s lane T row says the flip is done.
10. **Before the PR:** merge `origin/main`, keep both sides; `npm run lint && npm test && npm run build && node scripts/health.mjs --check --skip build && npm run coverage:bf2017`; the PR body carries the per-world table and two shots.
