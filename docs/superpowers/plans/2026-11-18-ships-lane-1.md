# Ships lane 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The four crews’ ships each fly with a character, and seven core systems, Mk I to Mk V, bought per crew in the Hangar, change how they fly and how their engines glow.

**Architecture:** A pure `src/components/universe/ships/` folder holds the profiles, the ladders and the tier items. Tiers are owned items in the one wallet (`economy.js`), so a tier and its price change together. `outfit.js`’s `statsOf` takes the core numbers as a sixth argument (none: today’s numbers, so the galaxy is untouched); `ship.js`’s `step` reads them from its tune. The page hands the scene the crew’s tiers as a prop.

**Tech Stack:** plain ES modules, Vitest, React (the tab only), three.js (the scene only).

**Spec:** `docs/superpowers/specs/2026-11-18-ships-market-exploration-design.md`, section 1, and “The lanes”, lane 1. The cargo pods and the scanner dish move to lanes 2 and 3, with the hold and the scanner they show.

## Global Constraints

- Pure first: `ships/*.js` import no React, DOM or three.js; each has its test beside it, under a second.
- Nothing a visitor has is lost: every save key reads as before; a save with no tiers is Mk I everywhere; `statsOf` with no sixth argument returns exactly what it does today.
- No new dependency. Draw calls and triangles unchanged at every checked route.
- British spelling, curly quotes, sentence case, comments say why. No model names anywhere.
- Before the pull request: `npm run lint`, `npm test`, `npm run build`, `node scripts/health.mjs --check --skip build`.

## Review Focus

- A crew with no tiers bought (every existing save): flies within ±15 % of today, the Hangar shows Mk I everywhere. Pinned in Task 1 and Task 4.
- A tier bought out of order (Mk III before Mk II, from a crafted save or a double click): refused; `tierOf` counts only the unbroken run from Mk II. Pinned in Task 2.
- Mk IV and Mk V before the market exists: locked with the rare named, never purchasable with credits alone. Pinned in Task 3.
- A garage build in the crew’s place: the neutral profile with the crew’s tiers, no signature. Pinned in Task 1.
- The galaxy, which calls `statsOf` with five arguments: unchanged numbers. Pinned in Task 4.
