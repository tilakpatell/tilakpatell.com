# The Road Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A continuous three.js journey from Bag End to the Grey Havens at `/middle-earth/road`, sixteen streamed stages performing the films’ set pieces round the visitor, a `'nodes'` module on the runtime, ending on the map hub where the games wait.

**Architecture:** One number, the progress `s` along a polyline of stages, drives everything (the clock, the director, the fellowship, the daylight, the beats), all in pure tested files; scene files only draw. Each stage is a folder with data (`index.js`, `beats.js`, `lore.js`) and a `build(ctx)`; the world keeps the current stage at the origin and re-roots at a stage’s edge. The cast is the Meshy figures on the shared skeleton through `lib/three/rig.js`, `animator.js`, `locomotion.js`, `clipLibrary.js`; the ground, scatter, water, sky, weather and post are the site’s nodes stack (`houseNodes`, `kitNodes`, `groundmapNodes`, `particles/`, `light/post.js`).

**Tech Stack:** three r186 `three/webgpu` + `three/tsl`, the world runtime (`src/runtime`), the HUD kit (`src/runtime/hud`), `lib/land`, `lib/three/particles`, vitest, playwright (the probe and the check scripts).

**Spec:** `docs/superpowers/specs/2026-10-18-the-road-design.md` (the design; §4.3 is each stage’s brief, §4.5 the creatures, §5 the copy). The map’s own plan, `2026-10-18-middle-earth-sheet.md`, is done (lane S): this plan’s Tasks 26 and 31 use its `sheet.js`.
