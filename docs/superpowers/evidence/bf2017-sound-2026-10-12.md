Headless Edge (`msedge.exe`, `--enable-unsafe-webgpu --use-angle=d3d11 --ignore-gpu-blocklist --enable-webgl --autoplay-policy=no-user-gesture-required`) on the owner's desk, a 1,280 × 720 viewport, `tp-quality=ultra`, WebGPU, the Vite dev server on `127.0.0.1:5611`, the route `/#/battlefront/hoth/galacticAssault?gpu=webgpu`. ## Why the feet did not plant

`module.js` gave the director the value `addPlayer` returns, which is the name the inputs go by (`'player'`). The sim's entities and events name the player's soldier `PLAYER_ID` (`'p0'`), so the director found no body in the view and never counted a stride; the player's own shots were still heard, as another soldier's at no distance. The director is given `PLAYER_ID` now, and `director.test.js` walks the real battle (the flat Hoth fixture) through it: a jog plants a foot every stride, a sprint the sprint set, a director told the input's name plants none. Two smaller things rode with it: the window weighed a plant at the movement patch's loudness less the speed's gain, so a walk's quiet plant could be dropped by a far shot, and it now weighs the patch's 75; and the cue on the player's own death was the Killed cue, which finding 36 lays under the kill confirmation, where it is now.

## A sound that is not there

| run | what was arranged | files asked | buffer sources started | console errors |
| --- | --- | ---: | ---: | ---: |
| `--gone` | the build told the set has left the checkout (`VITE_BF2017_SOUNDS=gone`, no bucket naming the files) | 0 | 0 | 0 |
| `--lost` | every sound file sent to a path that is not there, the build still saying it is | 243, once each | 0 | 0 |

In the first the player counts 51 calls it did not make (`absent`) and asks for nothing. In the second the dev server answers each with the site's page and a 200 (4,627 bytes of HTML), the decode fails 241 times, each file is remembered and not asked again, and the two stems' elements stay silent. Before this change that run raised 241 unhandled rejections: `lib/audio`'s `loadBuffer` listened to `decodeAudioData`'s callbacks and not to the promise it also returns. A host that answers a missing file with a 404 has the browser itself write a line in the console for each request, which no code can stop; that is why the build's word is asked first and such a file is never requested.

## Publishing the files

The 352 files are in git under `public/audio/galaxy/bf2017/` and the site serves them itself, so nothing waits on this. They are registered with the publish pipeline (`scripts/lib/asset-manifest.mjs`: `SOUNDS`, tier `sound`; `.mp3` goes up as `audio/mpeg`), and a dry run finds them: `node scripts/assets-publish.mjs --dry --only 'audio/galaxy/bf2017/*'` says 352 files, 12.4 MB, all new, nothing sent. The upload needs the owner's key, which this checkout does not hold:

```
# SUPABASE_URL and SUPA_KEY in the shell (the project's secret key, for the upload only)
node scripts/assets-publish.mjs --only 'audio/galaxy/bf2017/*'
node scripts/assets-check.mjs
git rm -r --cached --quiet public/audio/galaxy/bf2017
git add src/data/galaxyAssets.json .gitignore
git commit -m "The Hoth sounds published"
```

The publish writes the manifest and the ignore block; the `git rm --cached` takes the files out of git once the block names them. After that the deploy must have the repository variable `ASSET_BASE` set, as it is for the level pack: a build without it and without the files plays no sound, silently. The tests take a published sound on the manifest's word (`sounds.test.js`, `gameSounds.test.js`).

## What is left

- The sim's soldiers do not jump, so `step.jump` and `cloth.jump` wait on a `jump` event from it (the director answers one); the landing plays on a drop.
- The fly-by (`blaster.passby`, eight takes, fetched and never played): the sim keeps its bolts' `near` events to itself.
- The feet plant by the stride's length over the speed, not on the clip's own plants; `figures/stride.js` now measures each clip's strides and could give the phase.
- No reverb (the snow impulse response waits on finding 36's `irf1` layout), no occlusion, and the field's noise tail everywhere: the hangar's indoor tails are not in the set.
- The abilities' cues, the commanders' lines and the high and tension stems are wired and tested on fakes; this life did not reach them.
- Only Hoth has a set and a loading cue.
- Nobody has listened to it.
