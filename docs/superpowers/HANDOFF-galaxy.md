# Hand-off: the galaxy

The Star Wars galaxy at `/galaxy`: a map of systems joined by hyperlanes, flown in a crew’s ship; a world to land on at every system but Alderaan under it at `/galaxy/:id/surface`, each with places, quests and people, seventeen with zones and a ground war; three fleet wars on a shared clock with set pieces at Endor, Hoth and Scarif; the crews’ ship powers and ship-to-ship contact; low flight over endless ground at `/fly/:planet` with a shared, durable world; the inside of both Death Stars at `/deathstar/inside`; and a lit stack (three’s node renderer, TSL and Rapier) under the surfaces, fed by the 2017 game’s own level records. The code is the truth where this file disagrees with it.

- No sequel trilogy (Episodes 7 to 9) anywhere: no figure, place or name. After Episode 6 only The Mandalorian and Ahsoka.
- Every planet has unique things to do, not just “land and walk”. Tatooine is the model to copy.

- The asset upgrade uses no paid service: no Meshy, no Sketchfab API. Elsewhere the owner said to use Meshy where needed, and for stations overrode gen3d-first: Sketchfab CC BY first, then Meshy, then gen3d from a still.

- Sizes: a surface model under 2.5 MB (4 MB `hero`); a baked core set under 60 KB a figure; nothing under `lab/` is committed. Credits: Sketchfab in `src/data/modelCredits.json` (its test is the law), CC0 in `public/cc0/README.md`, `CREDITS.md` through `scripts/credits.mjs`.
- Never print or commit the Sketchfab, Meshy or Supabase keys. The client holds Supabase’s publishable key only; the secret key appears nowhere, and a session that finds one uses it for nothing and says so.
- Pure first: `src/lib/land/`, `src/lib/durable/` and `src/lib/net/` import no three.js and no React; tests beside each file, under a second, no network. A dependency has a page under `docs/stack/` before it is imported. Nothing a visitor can do is lost. Worlds are islands. The constants are the spec’s.
- One lane or phase per PR, merged on its own: PR to `main`, CI green, merge commit. Never merge red, never force-push, never rebase someone else’s branch, never skip or quieten a test. Before the PR: `npm run lint`, `npm test`, `npm run build`, `node scripts/health.mjs --check --skip build`.
