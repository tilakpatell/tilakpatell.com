# The planets' geographies: what each world's ground is, from the fiction, for the flight

Date: 2026-10-09. Written by the architecting session for lane A of `docs/superpowers/specs/2026-10-09-planet-flight-and-shared-world-design.md`: the reference `src/lib/land/flight/planetSpec.js` is built from. Each world below is one the site already has (the galaxy's systems, the universe map's fandom planets, the Rick and Morty sector's moons), so its flight ground must agree with what a visitor walks on there (`galaxy/surface/sites/*.js`, `universe/landings/*.js`, `rickmorty/planets/sites/*.js`): same places, same palette family, same sky. Where the walkable site already sums layers for a world, the flight's biome that holds the landing site reuses those layers, scaled, so the ground round the site is recognisably the same ground.

Sources: the official Databank and the Star Wars wiki mirrors for the galaxy; the Rick and Morty wiki for the moons; the Transformers wiki for Cybertron; the owner's own worlds for the rest. Secondary claims are marked. Nothing from Episodes 7 to 9.

## How to read a row

- **Biomes**: three to five a world, each `{ id, at: [t, m], reach, base, relief: [layers] }` on `layers.js`'s types (`swell, hills, dunes, mesas, ridges, mountains, channels, island, level`), heights in metres; `at` places it on the climate square (temperature across, moisture down, both 0 to 1) so the warped climate noise lays them out; `base` is its floor. `base` differences make slopes at the blend band; keep neighbours within 120 m of each other.
- **POIs**: `{ id, name, at: [x, z], r, edge, h }`: a flat the land eases into over `edge`; the walkable site's own `flats`/`places` become POIs here, at the same relative places where the site has them.
- **Palette**: the flight's `look` for that planet (low, high, rock, accent), from the site's own.
- **Clutter**: the kinds the worker scatters (`rock`, `spire`, `debris` are the base kinds; a world may name a fourth, built in code from the look's palette).
- **Field options** two worlds need and lane A adds to `planetField`: `step` (metres: heights snapped to a grid, for the pixel world), `blocks` (a layer: flat-topped towers on a grid, `{ type: 'blocks', cell, gap, hMin, hMax, cover }`, for the city worlds), `soft: true` (a cloud deck: flying into the ground is fog, not a crash).
