# Everything a visitor can do on tilakpatell.com

An inventory of every page, section, world, game, mission, mini-game, multiplayer feature, easter egg, tool, terminal command, palette item and achievement, as raw material for three tours (recruiter, player, mixed). Every row cites the file and line that proves it exists. Routes are hash paths (the site uses React Router's HashRouter, `src/App.jsx:382`): `/experience/aws` is `https://tilakpatell.com/#/experience/aws`.

The same rows are in `things-to-do.json` (an array of the row objects: id, title, route, kind, audience, oneLine, howTo, timeToTry, prerequisites, phone, evidence, showcase, group, deepLink, costly).

## How to read the columns

- **kind**: page, section, world, game, mission, mini-game, multiplayer, easter-egg, tool, achievement.
- **audience**: recruiter (shows the work and skills), player (games and lore), both.
- **timeToTry**: seconds a visitor needs to see the thing work once, not to finish it.
- **phone**: yes, partial (works, but with touch controls or a download prompt), no (keyboard only).
- **deepLink**: yes when the route opens straight on it; no when it needs state (inside a world, a random event, a first visit, a password); partial when a route gets near it.
- **costly**: a long download, an intro or crawl, a long mission, or a gate a tour cannot pass.
