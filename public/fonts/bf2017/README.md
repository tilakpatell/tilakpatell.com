# The 2017 game’s fonts

Every face in Star Wars Battlefront II (2017)’s drop, as the drop has it (scripts/bf2017-ui.mjs fonts): every font shipped; the owner holds the licence (2026-10-10). The open-licence ones also carry their own licence, whose text is beside them. `src/lib/bf2017/fonts.css` loads them; the CJK and Arabic faces load only for a glyph in their ranges.
